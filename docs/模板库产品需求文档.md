## 1. 产品范围

模板库是政务 AI 写作平台中的独立功能页面，用于管理两类可复用资产：

- **结构模板**：定义文稿的章节层级、章节生成方式、篇幅和参考文档。
- **风格模板**：定义文种、行文方向、受众、语气、人称、句式、用词、篇幅节奏和写作要求。

本需求不展开组织运营、商业指标等外围内容，主要回答以下问题：

1. 页面由哪些区域构成。
2. 每个区域展示什么、如何交互。
3. 浏览态、查看态、编辑态如何切换。
4. 结构库和风格库分别需要实现哪些功能。
5. 当前前端代码如何保存和处理数据。
6. 哪些地方仍是模拟实现或存在功能缺口。

## 2. 页面入口与页面状态

### 2.1 页面入口

- 桌面端：左侧导航“模板库”。
- 移动端：顶部导航“模板”。
- 页面视图标识：`template-library`。
- 页面由 `AppShell` 内部视图切换控制，当前不是独立 URL 路由。
- 原“模板写作”“风格写作”入口已从写作模式中隐藏；风格写作旧页面会自动跳转到模板库。

### 2.2 页面状态模型

模板库没有额外的详情路由，列表和详情由组件内部状态互斥渲染：

```text
模板库
├─ 结构模板页签
│  ├─ 列表态
│  ├─ 只读查看态
│  └─ 编辑态
└─ 风格模板页签
   ├─ 列表态
   ├─ 只读查看态
   └─ 编辑态
```

状态转换：

```text
列表态 ──查看──> 只读查看态 ──编辑──> 编辑态
   │                                      │
   ├─自定义创建──────────────────────────>├─保存──> 只读查看态
   └─文件提取────────────────────────────>├─取消──> 只读态或列表态
                                          └─返回──> 列表态
```

规则：

- 查看模板时保存一份快照，详情以只读态打开。
- 编辑已有模板后取消，恢复进入编辑前的快照。
- 创建或提取的新模板尚未保存时取消，直接回到列表。
- 点击“返回模板库”直接退出详情；当前没有未保存内容确认。
- 结构页签和风格页签分别保存自己的列表、搜索、置顶和编辑状态。

## 3. 模板库首页设计

### 3.1 页面整体布局

页面内容区最大宽度为 1120px，水平居中。由上到下分为四层：

```text
┌──────────────────────────────────────────────────────────┐
│ 页面标题：模板库                                         │
│ 说明：管理和复用结构模板与风格模板……                     │
├──────────────────────────────────────────────────────────┤
│ [结构模板] [风格模板]                                    │
├──────────────────────────────────────────────────────────┤
│ [自定义创建] [AI从文件提取]   共 N 个模板  [搜索模板...] │
├──────────────────────────────────────────────────────────┤
│ 模板卡片网格                                             │
│ [卡片] [卡片] [卡片]                                    │
└──────────────────────────────────────────────────────────┘
```

页面视觉要求：

- 页面标题使用 27px 左右的大标题，副标题为 13px 弱化文本。
- 结构、风格通过图标和文字区分：结构使用网格图标，风格使用调色板图标。
- 当前页签使用浅红背景、深红文字和弱红边框。
- 内容卡片使用白色半透明背景、圆角和浅边框，悬停时轻微抬升并增加阴影。
- 核心操作使用红色系；次要操作使用白底描边。

### 3.2 响应式布局

| 屏幕范围 | 模板卡片布局 | 规格表布局 | 操作栏 |
| --- | --- | --- | --- |
| 大屏 | 3 列 | 2 列 | 单行优先 |
| 中屏 | 2 列 | 2 列 | 空间不足时换行 |
| 小屏 | 1 列 | 1 列 | 按钮、上传、搜索自动换行 |

实现要求：

- 卡片网格使用 `1 / 2 / 3` 列响应式切换。
- 操作栏采用可换行布局，搜索框不得压缩到不可输入。
- 编辑页的表单项在小屏幕下改为单列。
- 标题、模板名、文件名需支持截断，不能撑破卡片。

## 4. 页签与公共操作栏

### 4.1 页签

| 项目 | 结构模板页签 | 风格模板页签 |
| --- | --- | --- |
| 图标 | LayoutGrid | Palette |
| 初始状态 | 默认选中 | 未选中 |
| 切换结果 | 展示结构列表或当前结构详情 | 展示风格列表或当前风格详情 |

当前实现切换页签不会清空另一页签的详情状态。例如用户正在编辑结构模板，切到风格页签后再切回，仍会回到原结构编辑页。

### 4.2 公共操作栏

操作栏包含：

1. “自定义创建”按钮。
2. “AI 从文件提取”文件选择器。
3. 已选文件后的“开始提取”按钮。
4. 已选文件后的取消按钮。
5. 模板总数。
6. 模板名称搜索框。

#### 自定义创建

- 点击后立即创建空白模板并进入编辑态。
- 结构模板默认包含一个空白一级章节。
- 风格模板默认只有空名称、空规格和空要求列表。
- 达到数量上限时应禁止进入创建流程并提示原因；当前代码仍可进入编辑页，但保存时静默失败，需要修复。

#### AI 从文件提取

- 接受格式：`.docx`、`.pdf`、`.txt`。
- 选择文件后，按钮位置展示文件名。
- 点击“开始提取”后显示加载图标和“提取中...”。
- 提取期间禁止重复点击。
- 用户可以在提取前取消已选文件。
- 提取完成后不直接保存，而是打开编辑页供用户确认。
- 当前实现只把文件名传给模拟函数，没有上传或读取文件正文。

#### 模板数量

- 显示格式：`共 N 个模板`。
- N 为当前模板类型的总数，不随搜索结果变化。
- 当前上限为每类 10 个，包含系统预设。
- 结构库内置 3 个预设，因此最多新增 7 个用户模板。
- 风格库内置 6 个预设，因此最多新增 4 个用户模板。

#### 搜索

- 占位提示：`搜索模板...`。
- 仅搜索模板名称。
- 使用包含匹配，不区分英文大小写。
- 输入后实时过滤，无独立搜索按钮。
- 无匹配结果时复用空状态页面。
- 当前不支持按来源、文种、方向、更新时间等条件筛选。

## 5. 模板卡片设计

### 5.1 卡片公共结构

```text
┌──────────────────────────────────┐
│ [图标] 模板名称           [删除] │
│        摘要信息  来源标签        │
│                                  │
│ [复制] [置顶]       [查看]       │
└──────────────────────────────────┘
```

公共展示及交互：

- 模板名称单行截断。
- 置顶模板在标题旁展示小型图钉，并使用弱红边框。
- 预设模板不显示删除按钮。
- 非预设模板右上角显示删除按钮。
- 底部操作区固定包含复制、置顶/取消置顶、查看。
- “查看”占据剩余宽度，是卡片主操作。

### 5.2 结构模板卡片

展示内容：

- 结构图标。
- 模板名称。
- `N 个章节`。
- 来源标签：预设、文件提取、自定义。

### 5.3 风格模板卡片

展示内容：

- 调色板图标。
- 模板名称。
- 文种与方向，例如 `通知 · 下行`。
- 文种和方向均为空时显示“自定义风格”。
- 有写作要求时显示 `N 条要求`。
- 来源标签：预设、文件提取、自定义。

### 5.4 复制

- 点击后直接生成副本，不弹确认框。
- 副本名称为 `原名称 (副本)`。
- 副本获得新的模板 ID。
- 来源统一改为 `custom`。
- 创建、更新时间更新为当前时间。
- 复制预设是用户修改预设模板的唯一方式。
- 达到 10 个上限时当前代码静默无响应，目标实现必须显示“模板数量已达上限”。
- 结构模板副本当前沿用原章节 ID；正式实现应同时重建章节 ID，保证全局唯一。

### 5.5 置顶

- 每类模板最多置顶 3 个，结构与风格分别计数。
- 新增置顶前弹出确认框。
- 置顶达到上限时弹出只含“我知道了”的提示框。
- 已置顶模板再次点击图钉时立即取消置顶，不再确认。
- 置顶模板排序到未置顶模板之前。
- 当前排序只区分“是否置顶”，没有按照置顶先后顺序排序。
- 置顶状态单独写入本地存储。

### 5.6 查看和编辑权限

- 点击“查看”进入只读详情。
- 预设模板的“编辑”按钮禁用。
- 自定义或文件提取模板可从只读态进入编辑态。
- 预设模板可以从列表复制，但只读详情页中没有“复制为自定义模板”按钮。

### 5.7 删除

- 删除入口仅对非预设模板显示。
- 点击后弹出确认框，文案包含模板名称。
- 删除成功后同步从列表和置顶记录中移除。
- 删除的是当前详情模板时，应退出详情并回到列表状态。
- 删除不可撤销。

## 6. 结构模板详情与编辑页

### 6.1 页面布局

```text
┌────────────────────────────────────────────────────┐
│ [← 返回模板库]                         [编辑/取消] │
├────────────────────────────────────────────────────┤
│ 模板名称 *                                         │
├────────────────────────────────────────────────────┤
│ 一级章节卡片                                       │
│   二级章节卡片                                     │
│   二级章节卡片                                     │
│ 一级章节卡片                                       │
├────────────────────────────────────────────────────┤
│ [+ 添加章节]                                       │
│ [保存] [另存为新模板]                              │
└────────────────────────────────────────────────────┘
```

详情容器采用白色半透明背景、圆角、浅边框和 24px 左右内边距。

### 6.2 顶部操作

| 状态 | 右上角按钮 | 行为 |
| --- | --- | --- |
| 只读预设 | 禁用的“编辑” | 鼠标提示“预设模板不可编辑” |
| 只读用户模板 | “编辑” | 进入编辑态并保留快照 |
| 编辑已有模板 | “取消编辑” | 恢复快照并回到只读态 |
| 编辑新模板 | “取消编辑” | 丢弃未保存模板并返回列表 |

“返回模板库”在所有状态可用。目标实现应在存在未保存修改时弹出离开确认。

### 6.3 模板名称

- 必填。
- 编辑态使用单行输入框。
- 只读态使用文本展示。
- 当前不校验重名。
- 保存按钮必须在名称非空时才可能启用。

### 6.4 章节层级

结构模板只支持两级标题：

- 一级标题：独立白色卡片，使用圆形序号，例如 `1`。
- 二级标题：向右缩进，使用较浅背景和文本序号，例如 `1.1`。
- 页面序号根据数组顺序实时计算，不保存到标题文本中。

章节操作：

| 操作 | 一级标题 | 二级标题 |
| --- | --- | --- |
| 新增 | 在模板末尾添加 | 在指定一级标题末尾添加 |
| 上下移动 | 整组移动，子标题跟随 | 仅在同一父标题内移动 |
| 删除 | 删除自身及全部子标题，需要确认 | 仅删除自身，需要确认 |
| 转换层级 | 可转为下方一级标题的二级标题 | 可提升为新的一级标题 |

一级标题降级的当前规则：

1. 必须存在下方一级标题。
2. 当前一级标题及其所有子标题整体变为二级标题。
3. 归入下方一级标题，并插入为该父标题最前面的子标题。

此规则理解成本较高，目标页面应在操作前说明目标父标题，或改为让用户选择父标题。

### 6.5 章节标题

- 所有章节标题必填。
- `fixedTitle` 字段已存在，但当前没有单独锁定标题的界面。
- 预设模板通过整个页面只读实现标题保护。
- 文件提取结果不应把 `一、`、`1.` 等序号写入标题，避免与页面自动序号重复。

### 6.6 章节生成方式

每个章节必须选择一种写作模式。

#### 提示词模式

- 展示“提示词”选择状态。
- 文本框用于描述 AI 应如何生成该章节。
- 示例：`说明发文背景、政策依据和工作目的`。
- 提示词不能为空，否则模板不可保存。

#### 文本+占位符模式

- 展示“文本+占位符”选择状态。
- 用户输入需要保留的固定文本。
- 使用 `{{占位符名称}}` 标记需要 AI 填充的位置。
- 支持在光标位置插入 `{{}}`，插入后光标位于括号内部。
- 页面自动识别并展示占位符标签。
- 占位符名称会去除首尾空格并去重。
- 即使没有占位符，只要存在固定文本也允许保存。
- 填充模板为空时不可保存。

### 6.7 篇幅范围

- 最少字数、最多字数都允许为空。
- 输入框仅接受非负数字。
- 两者同时填写时，最少字数不得大于最多字数。
- 校验失败时在字段右侧显示“最小不能大于最大”。
- 存在无效章节时，整个模板的保存按钮禁用。

### 6.8 参考文档

仅一级标题显示参考文档编辑器。

本地上传：

- 接受 `.docx`、`.pdf`、`.txt`。
- 选择后显示文件名。
- 用户还需点击“添加此文件”才进入已添加列表。
- 当前只保存文件名和来源，没有保存文件内容或上传后的文件 ID。

知识库选择：

- 展示当前全局状态中的知识库文件。
- 单选一个文件后点击“添加此文件”。
- 已添加文件禁用并显示“已添加”。
- 知识库无文件时展示空提示。

公共规则：

- 已添加列表显示文件名和来源。
- 可从列表移除。
- 当前按文件名去重，因此不同来源的同名文件不能同时添加。
- 只读态仅在存在参考文件时展示列表。

### 6.9 保存与另存为

保存按钮启用条件：

```text
非只读
AND 模板名称非空
AND 至少一个章节
AND 所有章节标题非空
AND 所有章节篇幅范围有效
AND 所有章节当前写作模式内容非空
```

保存结果：

- 已存在 ID：更新原模板。
- 新 ID：追加到模板列表。
- 更新 `updatedAt`。
- 保存后切换到只读查看态。

另存为新模板：

- 打开名称输入弹窗。
- 默认名称为 `当前名称 (副本)`。
- 名称非空才允许确认。
- 创建新模板 ID，并将来源改为自定义。
- 达到模板上限时按钮禁用。

## 7. 风格模板详情与编辑页

### 7.1 页面布局

```text
┌────────────────────────────────────────────────────┐
│ [← 返回模板库]                         [编辑/取消] │
├────────────────────────────────────────────────────┤
│ 模板名称 *                                         │
├────────────────────────────────────────────────────┤
│ 公文规格                                           │
│ [文种] [行文方向]                                  │
│ [受众] [语气]                                      │
│ [人称] [句式]                                      │
│ [用词] [篇幅节奏]                                  │
├────────────────────────────────────────────────────┤
│ 写作要求                                           │
│ [↑↓] 1 [要求内容........................] [删除]   │
│ [+ 添加写作要求]                                   │
├────────────────────────────────────────────────────┤
│ [保存] [另存为新模板]                              │
└────────────────────────────────────────────────────┘
```

顶部操作、名称编辑、保存和另存为的状态逻辑与结构模板一致。

### 7.2 公文规格

| 字段 | 控件 | 可选值/输入方式 |
| --- | --- | --- |
| 文种 | 下拉框 | 通知、请示、报告、批复、函、纪要、通报、讲话、简报、调研报告、工作总结、其他 |
| 行文方向 | 下拉框 | 上行、下行、平行、对内、对外 |
| 受众对象 | 文本框 | 自由输入 |
| 语气 | 文本框 | 自由输入 |
| 人称偏好 | 文本框 | 自由输入 |
| 句式 | 文本框 | 自由输入 |
| 用词 | 文本框 | 自由输入 |
| 篇幅节奏 | 文本框 | 自由输入 |

文种推荐规则：

- 选择常用文种后，系统自动填充对应推荐规格。
- 推荐值会整体替换现有规格，不是只填空字段。
- 用户可在推荐值基础上继续修改。
- 当前选择“其他”后会把文种本身也清空，应修复为保留 `documentType = 其他`，其余字段为空。
- 如果用户已经手工编辑规格，再切换文种，目标实现应提示“将覆盖当前规格”。

### 7.3 写作要求

- 写作要求是有序字符串列表。
- 支持新增空白条目。
- 支持修改、删除、上移和下移。
- 第一条禁用上移，最后一条禁用下移。
- 每条前显示从 1 开始的序号。
- 保存时去除首尾空格，并删除空白条目。
- 只读态没有移动和删除入口。
- 只读态无要求时显示“暂无写作要求”。

### 7.4 保存校验

当前风格模板仅要求名称非空，公文规格和写作要求均可为空。保存后逻辑与结构模板一致。

建议增加最低有效性校验：除名称外，至少填写一个规格字段或一条写作要求，防止产生没有实际约束的风格模板。

## 8. 弹窗和提示设计

| 弹窗 | 触发时机 | 主要内容 | 操作 |
| --- | --- | --- | --- |
| 置顶确认 | 新置顶 | 是否置顶指定模板 | 取消、置顶 |
| 置顶上限 | 已置顶 3 个后继续置顶 | 最多可置顶 3 个 | 我知道了 |
| 删除模板 | 删除非预设模板 | 模板名、不可撤销提示 | 取消、删除 |
| 删除一级标题 | 删除一级标题 | 将同时删除其全部二级标题 | 取消、删除 |
| 删除二级标题 | 删除二级标题 | 仅删除当前标题 | 取消、删除 |
| 另存为 | 点击另存为新模板 | 输入新模板名称 | 取消、确认创建 |

当前缺少但应补充：

- 达到模板数量上限提示。
- 保存成功或失败提示。
- 本地存储失败提示。
- AI 提取失败提示。
- 存在未保存修改时离开确认。
- 文种推荐值覆盖确认。

## 9. 空状态和加载状态

### 9.1 空状态

结构库无结果：

- 结构图标。
- “暂无结构模板”。
- “点击‘自定义创建’或‘AI 从文件提取’来添加”。

风格库无结果：

- 风格图标。
- “暂无风格模板”。
- 相同的创建提示。

需要区分两种情况：

- 库中确实没有模板。
- 有模板但搜索无结果。

当前两种情况使用同一文案，建议搜索无结果时显示“未找到匹配模板”和“清空搜索”。

### 9.2 加载状态

- 文件提取期间按钮显示旋转图标。
- 文案从“开始提取”变为“提取中...”。
- 按钮禁用并降低透明度。
- 当前没有骨架屏、进度百分比和取消正在执行的提取任务。

## 10. 前端功能实现

### 10.1 组件划分

| 组件 | 职责 |
| --- | --- |
| `TemplateLibraryView` | 双页签、列表与详情状态、模板增删改查、置顶、搜索、保存 |
| `ActionBar` | 创建、文件选择、提取、数量和搜索 |
| `StructureBrowsePanel` | 结构模板列表与空状态 |
| `StyleBrowsePanel` | 风格模板列表与空状态 |
| `TemplateLibraryCard` | 结构模板卡片、置顶确认和上限提示 |
| `StyleLibraryCard` | 风格模板卡片、置顶确认和上限提示 |
| `StructureEditPanel` | 结构模板查看和编辑 |
| `StyleEditPanel` | 风格模板查看和编辑 |
| `SectionCard` | 单个章节的层级、生成方式、篇幅和参考文档 |
| `ReferenceFilesEditor` | 本地或知识库参考文档选择 |
| `ConfirmDialog` | 删除、置顶等确认和通知 |

### 10.2 核心状态

结构、风格各自维护以下状态：

| 状态类型 | 作用 |
| --- | --- |
| `templates` | 当前模板列表 |
| `pinnedIds` | 已置顶模板 ID |
| `editing` | 当前正在查看或编辑的模板；为空时显示列表 |
| `readOnly` | 区分只读查看和编辑 |
| `snapshot` | 取消编辑时恢复的已保存快照 |
| `uploadName` | 当前已选择的提取文件名 |
| `extracting` | 是否正在提取 |
| `deleteTarget` | 等待确认删除的模板 |
| `search` | 名称搜索词 |
| `saveAsNewOpen/name` | 另存为弹窗和新名称 |

### 10.3 列表派生逻辑

列表展示顺序：

1. 复制当前模板数组，避免直接修改状态。
2. 根据 ID 是否存在于 `pinnedIds`，将置顶模板排到前面。
3. 根据搜索词过滤模板名称。
4. 将结果传给卡片网格。

当前没有更新时间排序、名称排序、来源筛选和文种筛选。

### 10.4 结构章节数组

结构章节在数据层使用扁平数组保存，通过以下规则在页面转换为分组：

```text
[一级A, 二级A1, 二级A2, 一级B, 二级B1]
             ↓
[[一级A, 二级A1, 二级A2], [一级B, 二级B1]]
```

- 移动一级标题时交换整个分组。
- 移动二级标题时只交换分组内部元素。
- 所有操作完成后重新生成连续的 `order`。
- 如果读取到没有父级的二级标题，当前逻辑会临时按一级标题处理，避免页面崩溃。

### 10.5 预设识别

当前通过 `template.id.startsWith("preset-")` 判断预设模板。正式数据模型应增加明确字段，例如：

```ts
templateType: "system" | "user" | "department"
```

避免用 ID 命名约定承担权限判断。

## 11. 数据与本地存储

| 数据 | 本地存储键 |
| --- | --- |
| 结构模板 | `template-write-templates` |
| 风格模板 | `style-write-templates` |
| 结构置顶 | `template-library-struct-pinned` |
| 风格置顶 | `template-library-style-pinned` |

读取规则：

- 没有本地数据时返回系统预设。
- 有本地数据时与系统预设按 ID 合并。
- 本地同 ID 模板会覆盖预设。
- 结构模板读取时补齐层级、写作模式、填充文本和参考文件等新字段。
- 风格模板读取时兼容旧版 `dimensions`、`styleNote` 并迁移到新模型。
- 解析失败时回退到系统预设。

当前限制：

- 数据只存在当前浏览器，不能跨设备同步。
- 清理浏览器数据会丢失用户模板。
- 保存失败被静默忽略。
- 没有用户、部门和组织级数据边界。
- 没有版本、创建人、更新人和审计记录。

## 13. 当前功能缺口与修复优先级

### P0：影响基本可用性

1. AI 文件提取只根据文件名返回模拟结果，没有读取文件内容。
2. 模板库没有“使用模板写作”入口，模板数据没有进入聊天请求。
3. 达到模板数量上限时，创建、复制、保存缺少明确提示。
4. 选择风格文种“其他”后文种值被清空。
5. 返回列表时没有未保存内容确认。
6. 本地存储写入失败被静默忽略。

### P1：影响一致性和维护性

1. 切换文种会覆盖全部手工规格，没有确认。
2. 预设身份依赖 ID 前缀。
3. 结构模板复制后章节 ID 未重新生成。
4. 文件和知识库引用仅按名称去重，没有稳定文件 ID。
5. `required`、`fixedTitle` 已存在于模型但界面不可配置。
6. 提取后的标题可能自带序号，与页面序号重复。
7. 风格模板只校验名称，可能保存无实际内容的空模板。

### P2：体验增强

1. 支持来源、文种、方向筛选和多种排序。
2. 搜索无结果与库为空使用不同空状态。
3. 详情页增加“复制为自定义模板”和“立即使用”。
4. 支持拖拽调整章节和写作要求顺序。
5. 支持模板预览、版本历史和组织共享。
